# Legacy engine adapter design

M07 adapter plan dựa [596 module map](../legacy-audit/module-map.md), [feature inventory](../legacy-audit/feature-inventory.md), [data flow](../legacy-audit/data-flow.md). Signatures dưới được đọc lại bằng AST từ file nguồn chỉ đọc; không import/chạy engine. Không copy toàn project, không dùng PYTHONPATH trỏ live source, không gọi app/background_worker entry point, không sửa project gốc. Tên Axx là thiết kế adapter, chưa có source file được tạo.

## Adapter envelope và boundary

M05 gửi TaskEnvelope tại [API contracts](api-contracts.md) gồm job/attempt/fence/lease/lineage/budgets/binding/version/input assets. M13 materialize workspace-private folder từ asset/checkpoint verified, chạy một bounded task trong process riêng. Adapter trả ArtifactManifest + CheckpointProposal + actual binding evidence/ErrorDTO; M08/M09 kiểm và commit canonical. Không dùng metadata.json hay `.jobs` legacy làm scheduler authority; chúng chỉ là format I/O tương thích trong spool.

Contract ports tương lai: TextWriter `write(prompt, invocationContext) -> {text,binding,evidence}`; StructuredWriter `writeStructured(prompt,schema,context)->{object,binding,evidence}`; AssetReader/Writer resolved IDs (không public raw path); CheckpointStore `load(lineage,stage,ordinal)` và `propose(manifest,fence)`; ProgressSink sanitized counters; InvocationPermit trước **mỗi** external call; CancellationToken/Deadline/BudgetLedger enforce tại callback. Không monkey patch runner toàn cục hoặc dùng subclass đổi slot mà vẫn hidden retries/account failover.

## Những module bị thay thế hoàn toàn

M05 thay `job_manager`, `background_worker`, Excel/SmartRetry/SmartContinue/auto retry workers và global Axcel coordinator lifecycle. M01/M02/M03/M12 thay Streamlit app/render/helpers, session/query-state, filesystem ID allocator/history/UI prefs/marks/status grid JS. M15 thay SQLite pool/stage gates/history/publisher canonical storage; không chạy migration SQLite tự mở file live. M13 thay cloudflare subprocess controls bằng service operations/health; web không start arbitrary tunnel. Legacy installers/TRANSFORM/VERIFY/live-check scripts không nằm runtime dependencies. Facebook client/store semantics chỉ compatibility feature off đến activation decision/tests. UI aliases/hidden legacy controls không tự phục dựng chỉ vì module được import.

Các pure algorithms có thể tái sử dụng: caption counts/normalization, current B2 dual markers/checks, Leader5 validators/heading assembly/context, story-video validation/FFmpeg recipe, TYPE fairness score, Excel/report parsing/normalization, URL validation/public link selection, safe error classification. Mỗi extraction giữ origin path/line/source SHA từ Phase01 và list dependency closure; không import `.codex_accounts`, `.runtime`, vendor/plugins, source outputs hay installer để “tự patch”. Adapter build allowlist riêng, hash drift→block reviewed port, không tự theo patch newest file name.

## Compatibility spool layout (target-only)

```text
asset namespace (outside repository, independent from legacy production)
  objects/<org>/<workspace>/<sha-prefix>/<sha>
  attempts/<jobId>/<attemptId>/<fence>/
    input.txt, caption.txt, content.txt, image_prompt.txt, video_prompt.txt
    node2.json, metadata.json             [generated compatibility snapshot]
    story_plan.json
    node3_parts/part_01.md ... part_05.md  [validated checkpoint materialization]
    full_story.txt, full_story.md, node3_report.json
    chatgpt_opening_image.png, .mode2_opening_image.json
    grok_agent_20s/<request-prefix>/checkpoint.json
      clip_01..., clip_01_last_frame.png, clip_02_input.json, clip_02..., video_20s.mp4
    axcel_video/final_video.mp4, first_frame... [logical mapping from source constants]
    adapter_receipts.jsonl, proposed_manifest.json
```

Không materialize raw auth/provider home trong spool; profile alias→local agent mới resolve. Relative paths từ legacy checkpoint phải resolve trong copied snapshot/spool, reject `..`, absolute outside root, UNC, ADS, symlink/junction/reparse. Legacy absolute pointers được đưa vào quarantine mapping, không follow tự động. `app_root` của adapted engine phải adapter-package readonly resources/schemas, không source production root. No legacy `.jobs` start path.

Hash profiles: asset bytes raw SHA-256; `text_utf8_lf_v1` cho new canonical text (UTF-8 LF, no silent trim content); `legacy_utf8_strip_v1` giữ cách hash `read_text(...).strip()` đúng modules gốc cho import checkpoint, kèm raw hash và normalized hash riêng. Không normalize lại rồi so với stored legacy hash. Request/plan/body canonical JSON sorted keys NFC policy có version; text prose không NFKC biến đổi. Missing hash/version→unverified historic record, không fake complete hay regenerate.

## Adapter verification gates

Dry-run compatibility uses synthetic clean tree, fake provider callbacks, fake process/browser/download agents, no old worker execution. Compare output validation+artifacts+side effects count, not AI prose equality. T03–T10, T18–T32, T43–T54 cover contracts; adapter tests additionally prove0child spawn at import,0outside-root writes, no account switch, permit for every call, cancellation budget, no hidden retries, stale fence cannot promote, recover-only0AI, image-save-blocked distinct rejection, frame0 vs last-frame. AST extraction signatures alone không là behavioral proof.

If extraction cannot isolate submit hooks/secret boundary, disable native adapter and use manual text/image/video upload or external verified import; UI shows capability unavailable. Do not retain a dangerous full legacy coordinator simply to claim parity. U02/U03/U05 gates tại [risk register](../legacy-audit/risk-register.md) phải đóng bằng evidence trước enabling live portions.
