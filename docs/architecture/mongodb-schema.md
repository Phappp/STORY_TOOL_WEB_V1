# MongoDB schema — V1

Thiết kế, chưa tạo MongoDB hoặc migration source. Phụ thuộc [system boundaries](system-design.md), [transaction/lease protocol](job-orchestration.md), [API schemas](api-contracts.md), [security](security-design.md), [migration](../migration/migration-plan.md). MongoDB canonical cho state/metadata; NTFS immutable store canonical cho asset bytes; raw OAuth/Codex auth/cookies/password/TOTP và video không được lưu MongoDB, kể cả field “debug” hay backup log.

## Deployment choice

Chọn **single-node replica set** thay standalone vì multi-document transaction claim job + resources + events/idempotency cần atomicity. Change streams optional wake-up. V1 primary một node, WiredTiger, authenticated loopback; majority writeConcern với j=true, transactions readConcern=snapshot/readPreference=primary; ACK không chứng minh disk ngoài host được replicate. Standalone không đủ contract nên readiness từ chối. Single node vẫn single point of failure, RPO/RTO dựa backup; thêm worker host không tạo DB HA. Nguồn khả năng nền tảng tại [ADR02](decisions.md).

Tên replica-set hostname phải resolve ổn định trên máy service sau reboot; localhost binding và Windows firewall không cho LAN vào27017. Auth internal replica key và admin credential là host secrets; không commit config thực. Least-privilege DB users: runtime service theo collections; migration schema role chỉ maintenance; backup role riêng. Worker/browser/Next không có Mongo credentials. Không dùng automatic fallback standalone nếu primary lỗi.

## Quy ước schema và validation

Notation thiết kế `name:type` required, `name?:type` optional **absent thay null** trừ chỗ ghi null. `ID` là string UUID (36ký tự, lowercase canonical); API dùng ID này, BSON `_id` cùng ID. `H` string lowercase SHA-256(64hex); `T` BSON Date UTC; `N` BSON long không âm≤2^53−1 để JSON an toàn; `I` int; `S(n)` string max n UTF-8 characters; `E(a,b)` enum; `[X;k]` array max k, items type X; `Ref` là ID cùng org/workspace trừ host/account grant được kiểm riêng. `Map` chỉ dùng nơi chỉ rõ allowed keys; không arbitrary Mongo document từ client. Max serialized domain document1MiB (jobs256KiB, events8KiB); text lớn/media nằm asset store. Không unbounded arrays embedded.

Mọi domain document có envelope `B={_id:ID,schemaVersion:I=1,orgId:ID,workspaceId?:ID,version:N>=1,createdAt:T,updatedAt:T,createdBy:ID}`. Workspace-required collections đánh **W**; org-required **O**; system control **X** dùng reserved system org và chỉ internal service access. `createdBy` actor ID user hoặc service principal có audit provenance. Update theo version predicate, tăng version, timestamps server. Immutable records version=1 và không update ngoài retention tombstone cho phép. Referenced IDs phải cùng scope, kiểm trong transaction; Mongo không có foreign key/RBAC row-level nên API repositories **luôn** inject scope, không endpoint raw filter.

Validation plan: `$jsonSchema` `bsonType:object`, `required` gồm envelope và fields không `?` của bảng, `additionalProperties:false` ở mỗi nested schema, enum/pattern/min/max/maxItems như DSL; DB `validationLevel:strict`, `validationAction:error`. Numeric/string JSON types chuyển BSON theo schema ở repository. Cross-field (end>start, same scope, no duplicate aliases, active→lease, state transitions, URL write-once, checkpoint lineage) kiểm bằng command validators + conditional updates/transactions, không chỉ jsonSchema. SchemaVersion discriminator; unknown version quarantine, không silently coerce. Validator/index upgrade theo versioned maintenance migration, chạy duplicate preflight trước unique index.

## Transaction boundaries và FS saga

| TX | Atomic records / predicate | Không nằm trong transaction |
|---|---|---|
| TX01 create/command | idempotency claim + workspace ownership/counter + Story/revision/run/jobs + audit/events/sequence | Provider/file generation; API trả202 chỉ khi committed |
| TX02 claim | Candidate job state=queued, notBefore≤serverNow, same revision/generation; update Story control reservations (write), ordered resource slot docs (write), worker heartbeat gate, attempt+lease epoch, first event | Spawn child sau commit; callback transaction tuyệt đối không submit AI/browser |
| TX03 heartbeat | owner host/boot/attempt/epoch và lease chưa hết; update job lease + **tất cả resource leases** | Nếu bất kỳ predicate không matched → abort, worker fail closed |
| TX04 checkpoint promote | Job fence/current lease + lineage + verified assets/refs + checkpoint + Story projection fields + terminal/events/release resources | Bytes chuẩn bị trước bằng FS saga; không sửa whole Story document từ child |
| TX05 metadata/manual/LINK | version CAS + membership + Story mutation conflict gate + revision hoặc write-once link + audit | Bulk≤200cells/TX (legacy bulk2000 chia thành plan/chunks, trạng thái partial hiển thị); không remote publish |
| TX06 cancel/pause/recovery | control intent + state/event, quarantine uncertain slots, revoke lease/epoch; scheduler/policy change đụng control doc để serialize claim | OS tree kill/remote cancel là best-effort bên ngoài |
| TX07 migration | Commit một item/chunk≤100records/1MiB, source hash + target ID unique, journal + audit | File copy/checksum trước TX; không transaction bao toàn bộ project |
| TX08 external receipt | prepare/submit_intent bằng CAS; verified result→publication/link/export state/events cùng promotion | Remote side effect không atomic với Mongo; ambiguous giữ operationId và resource quarantine |

Mongo transaction giữ ngắn, target<2s, retry write-conflict tối đa3 trước503 RETRY_LATER; unknown commit result retry commit theo driver contract/read idempotency record, **không** thực hiện remote side effect lại. Hard max transaction runtime10s tại app budget; chỉ IDs/small manifests ở transaction. TX02 worker capability/revocation doc và workspace gates phải write/touch để concurrent revoke/claim không write-skew.

Asset saga: allocate asset(staging) → stream vào `.partial` task spool → flush/fsync, hash, sniff/probe + source stable check → atomic rename cùng volume tới objectKey immutable → TX ghi verified+refs/checkpoint/state. Nếu crash trước TX: orphan object không hiển thị, reconcile theo sha+attempt, không generation lại. Nếu TX commit response mất: đọc receipt/idempotency. Nếu DB ref có nhưng object mất: quarantine/needs_reconciliation, không complete giả. GC chỉ unreferenced object ngoài retention/grace, workspace maintenance barriers và backup pins, không theo một cached refCount. Duplicate verified hash unique dùng record có sẵn + add refs cùng scope.

## Retention, backup và restore

Default đề xuất G03, chưa chạy: Stories/revisions/prompts/checkpoints giữ đến explicit purge; trash30ngày rồi preview purge với references/holds, không xóa unresolved submission. Job summaries/attempts365ngày (cần backup archive trước purge); progress events30ngày; audit365ngày; sanitized diagnostic files14ngày; terminal host commands7ngày; abandoned upload24h; idempotency24h complete; user session expiry như security (TTL chỉ cleanup). Submission ambiguous/publication chưa reconcile giữ vô thời hạn cho tới quyết định operator có evidence; GC không phá evidence/rollback. History/exports metadata giữ365ngày hoặc theo workspace hold. Retention chỉnh bởi admin có preview ảnh hưởng và audit, không TTL-delete jobs/leases/checkpoints/assets.

Mục tiêu RPO24h/RTO4h một host, **chưa đạt bằng chứng restore**. Daily encrypted offline/off-host backup, giữ7daily+4weekly+3monthly. Backup barrier chặn mọi mutating TX/claim, đợi active inference/publication tại safe boundary hoặc drain/reconcile xong, revoke sessions writes/agent commands và tạm dừng TTL monitor bằng thủ tục local DB admin có audit; không dump khi writers còn sống. Immutable assets/canonical refs pinned tại checkpoint B. Dump DB consistent trong quiescence (hoặc future tested --oplog full dump); copy referenced objects và manifests + hash list; snapshot schema/index/adapter build và encryption key escrow riêng. Không backup raw provider credentials vào DB/data artifact set. Host secret recovery theo local secure backup riêng hoặc re-login, DPAPI không portable.

Restore drill sang namespace/DB cách ly, queue dispatch off, TTL/reapers off, schema version hợp lệ; verify dump integrity, unique indexes/validators, asset hash+reference counts, source/target counts, ownershipEpoch tăng và boot IDs vô hiệu. Sessions revoked; all active jobs→needs_reconciliation/paused, no external replay; validate bằng fixtures và kiểm tra sign-off. Chỉ đổi active namespace khi reconcile đạt; không restore đè production đang chạy; rollback giữ namespace cũ đọc-only. Details tại [migration plan](../migration/migration-plan.md).
