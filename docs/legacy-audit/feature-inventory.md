## Hợp đồng xuyên suốt cần giữ

1. UI Bước1…5 không trùng tên B1/B2 nội bộ Node2. Bước1 = Caption; Bước2 = Content rewrite B1 + visual B2; Bước3 = PLAN/ACT; Bước4 = ảnh; Bước5 = video. Axcel bỏ B2 và dùng Caption làm source B3. Manual Web có validator riêng.
2. File tồn tại, `job.complete`, cờ operator Done và output đạt validator là bốn bằng chứng khác nhau. Không dùng một cờ thay tất cả.
3. Resume phải kiểm tra source/prompt/reference hash và format; FORCE là thao tác khác. Mỗi request sinh media cần tính đến submit receipt và file tải muộn.
4. Local lock, SQLite lease và PID birth là cơ chế một máy. Chưa có bằng chứng về phân quyền người dùng, tenant isolation, scheduler nhiều host hoặc distributed lease.
5. Không sao chép credential/session cũ sang Web App; chỉ thiết kế hợp đồng adapter và secret reference trong giai đoạn sau. Phase01 không tạo Next.js/FastAPI hay di chuyển dữ liệu.
